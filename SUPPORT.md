# ❓ Questions & Discussions

If you have a question about using a project or want to discuss an idea, please use **GitHub Discussions** (if enabled).

Examples include:

- Usage questions
- Best practices
- Project ideas
- Community discussions
- General help

---

# 🐞 Bug Reports

Found a bug?

Please open a **GitHub Issue** using the **Bug Report** template and include:

- A clear description of the problem
- Steps to reproduce
- Expected behavior
- Screenshots (if applicable)
- Environment details (OS, browser, versions, etc.)

---

# ✨ Feature Requests

Have an idea to improve a project?

Open a **GitHub Issue** using the **Feature Request** template.

Helpful information includes:

- The problem you're trying to solve
- Your proposed solution
- Alternative approaches you've considered
- Any additional context
